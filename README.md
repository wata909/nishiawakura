# 西粟倉 フィールド地図

https://wata909.github.io/nishiawakura/

岡山県西粟倉村を初期表示にしたスマホ向けWeb地図（PWA）。林野庁のCS立体図（岡山県全域 0.5m）に、地理院地図・主題図・GNSSログ・範囲保存（オフライン）を組み合わせています。
[wata909/fieldmap](https://github.com/wata909/fieldmap)・[wata909/hiruzen20260511](https://github.com/wata909/hiruzen20260511) と同じ仕組みです。

iPhone の Safari で開き「ホーム画面に追加」すると、アプリのように使えます。

## 画面下のツールバー
- **地図**：背景（標準・淡色・写真）＋ 地形（CS立体図・陰影起伏・色別標高）＋ 主題図1つ（地質・植生・地形分類・古写真）＋ 重ねるデータ（GNSSログ・筆ポリゴン・人口・旧市町村界・読込データ）
- **現在地**：現在地を表示し続ける
- **記録**：GNSSログの開始／停止、軌跡表示、GPX・GeoJSONで保存、消去（記録中は画面ロックを防止）
- **集水域**：💧を押して地点をタップ → 地理院DEM（10m）から上流の集水域を計算
- **保存**：今の画面の範囲を端末に保存（圏外で使えるように）。CS立体図も保存できる（1回1,500枚まで）
- **その他**：共有URL、文化財総覧WebGISへのリンク、GeoJSON読込、ZIP書き出し（GNSSログも入る。植生図・CS立体図タイルは不可）、出典

## CS立体図
- 配信元：林野庁「平成30年7月豪雨・DEM/微地形表現図/グラウンドデータ（林野庁加工）」[G空間情報センター](https://www.geospatial.jp/ckan/dataset/h30_7_gouu)
- タイル：`https://rinya-tiles.geospatial.jp/csmap_h3007tr_2025/{z}/{x}/{y}.webp`（z8–18）
- 元データ：林野庁の航空レーザ測量および岡山県公開のグリッドデータ（0.5m）
- 利用条件：公共データ利用規約（第1.0版）。村の東側（兵庫県）・北側（鳥取県）は範囲外
- 配信CDNがOriginごとにキャッシュを分けていないため、CORSヘッダが付くかどうかがタイルによって変わる。そのためアプリでは植生図と同じく「画像として表示・端末保存は可、ZIP書き出しは不可」として扱っている

## 出典
- CS立体図：林野庁（G空間情報センター、PDL1.0）
- 地理院タイル（国土地理院）
- 地質図：産総研地質調査総合センター「20万分の1日本シームレス地質図V2」（CC BY 4.0）
- 植生図：環境省生物多様性センター「現存植生図2024」
- 旧市町村界：歴史的行政区域データセットβ版（CODH）
- 筆ポリゴン：農林水産省「筆ポリゴンデータ（2022年度公開）」（農研機構 FlatGeobuf版）
- 人口：総務省統計局 国勢調査 地域メッシュ統計（e-Stat, 令和2年 500m）
